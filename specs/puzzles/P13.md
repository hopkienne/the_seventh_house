# P13 — Tuyến đường của bảy ký ức

**Chapter:** CH07. **Contract:** puzzle logic cụ thể để agent implement, không phải source đã có.

## Ý định và layout
Main subgraph align ba core nodes bằng E13 để mở A/B mà không cần M. Optional full route nối bảy segment từ H07 lên đồi, chỉ accessible khi đủ fragments.

## State graph
Main controller dùng `LOCKED → AVAILABLE → IN_PROGRESS → SOLVED`. LOCKED chỉ dùng khi thiếu chapter-entry/essential condition; không dùng optional memory để khóa main. `WRONG_INPUT` trả feedback và giữ IN_PROGRESS, không state terminal. `CAPTURE/LOAD` phục hồi state đã commit. SOLVED là monotonic; interaction repeated không phát thưởng lại.

Action order khuyến nghị: `inspect_core_map` → `align_three_core_nodes` → `unlock_main_choice` → `optional_connect_seven_fragments` → `validate_route`. Các bước inspect có thể được thực hiện lại; không buộc người chơi đi đúng thứ tự kiểm thử nếu dữ liệu đã hợp lệ.

## Inputs và outputs
Inputs: chapter ID, authoritative world phase, `action_id`, interacted `stable_id`, StoryState/Inventory/Journal readonly. Outputs: local state update, feedback key, optional once event và journal collect qua service; không trực tiếp ghi save hoặc sửa world mask.
`E13` được collect một lần theo interaction liên quan; `p13_solved=true` khi main puzzle đủ điều kiện. `evacuation_route_validated` là nhánh optional riêng, KHÔNG phải điều kiện main SOLVED.

## Persistence / reset
Snapshot: `state`, `completed_action_ids`, `slots` (dict), `inspected_ids` (set encoded array), `reward_committed` (bool). P13 thêm `optional_route_edges` và `route_validated`; P14 thêm `selected_ending`, `confirmation_committed` và `evacuation_groups_state`. Serialize IDs không Node references. Wrong input reset chỉ tentative slots khi cần, giữ clues đã collect. Reload mỗi intermediate state phải cho phép tiếp tục. `reset_local` trong debug không xóa progress của chapter khác; retail replay dùng checkpoint trước lựa chọn hoặc new slot.

## Acceptance / test fixture
- **P13-HAPPY:** từ entry state hợp lệ, dùng actions trên implementation thật tới SOLVED; assert reward đúng một lần và exit mở.
- **P13-WRONG:** đổi một lựa chọn/slot, feedback quan sát được, không SOLVED nhầm và sửa lại được.
- **P13-LOAD:** serialize/restore sau từng action; solve tiếp; reward không duplicate và flags không bị reset.
- **P13-EXPLOIT:** Không tất cả M thì main vẫn SOLVED; C flag không đặt từ core nodes; duplicate fragment không tăng count.
- **P13-ACCESS:** muted + reduced effects + large text + VI/EN, clue/feedback vẫn đọc được.

Evidence gồm unit/integration log, input replay và rendered capture đúng build. Không được đọc file đáp án rồi set solved bằng debug trong end-to-end test. Agent tạo runtime data ở `data/puzzles/P13.json`, adapter/controller trong `scripts/puzzles/` và fixture tại `tests/fixtures/puzzles/P13/`.
