# Prompt tiếp tục phiên thực thi
Tiếp tục dự án Ngôi Nhà Thứ Bảy từ repository hiện tại. Đọc AGENTS.md, state/session_handoff.md và state/task_state.json; chạy git status, python tools/validate_plan.py, python tools/agentctl.py summary và python tools/agentctl.py next. Đối chiếu files/log/build hash thật trước khi tin báo cáo cũ. Ưu tiên hoàn tất task IN_PROGRESS/IN_REVIEW hợp lệ; không mở task khác để né fail. Thiếu context thì đọc đúng task/story/contracts, không xây lại backlog. Tiếp tục implement → verify → review → evidence → ledger. Không reset DONE, không bịa test, không dùng phiên mới để vượt permission. Kết thúc bằng handoff cập nhật.
